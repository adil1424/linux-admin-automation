# Linux Administration Automation Scripts

This repository contains Linux system administration scripts that I use to automate
daily operational tasks such as health checks, patching, and backup validation.

## Scripts Included

- `system-health-check.sh` – Check CPU, memory, disk, load, top processes.
- `nfs-mount-check.sh` – Verify NFS mounts and alert if something is missing.
- `patching-automation.sh` – Run OS updates and log the results.
- `backup-verify.sh` – Verify that backups completed successfully.

> Tech stack: Bash, RHEL / Oracle Linux, Cron, NFS, SSH
